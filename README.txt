ميزانيتي — تطبيق ميزانية شخصي عربي
المحتويات: index.html, manifest.json, sw.js

التشغيل السريع:
1) ارفع الملفات الثلاثة إلى استضافة HTTPS مثل Netlify أو GitHub Pages.
2) افتح رابط الموقع من Chrome على أندرويد.
3) من قائمة ⋮ اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».
4) افتح التطبيق من الأيقونة. البيانات تحفظ محليًا على نفس الجهاز والمتصفح.

مهم: هذه نسخة PWA قابلة للتثبيت وليست APK. لا ترفع ملفاتك المالية إلى مكان عام؛ البيانات محفوظة في التخزين المحلي للمتصفح. استخدم زر الإعدادات لتصدير نسخة JSON احتياطية.
